# 콘텐츠 코드북

광고, 쇼츠, 영화 예고편, 뮤직비디오에서 반복해서 쓰이는 연출 공식 59개를 실제 작품으로 익히는 안목 훈련 앱입니다. SP미디어텍 내부용.

- 9개 분야: 훅, 스토리, 썸네일, 카피, 색, 조명과 구도, 편집, 사운드, 심리
- 코드마다 원리 도식, 공식, 디테일, 2040 사업 예와 어린이 콘텐츠 예, 실제 작품 영상
- 명작 사례 18개, 빌려오기 생성기, 상황 퀴즈

## 휴대폰에 설치
- 아이폰: 사파리로 페이지 열기 → 공유 버튼 → <홈 화면에 추가>
- 안드로이드: 크롬으로 열기 → 메뉴 → <앱 설치> 또는 <홈 화면에 추가>

## 구조
- `index.html` 앱 전체 (HTML, CSS, JS 한 파일)
- `manifest.webmanifest`, `sw.js`, `icons/` 홈 화면 설치와 오프라인용
- 수정 후 `sw.js`의 VERSION 숫자를 올려야 휴대폰에 새 버전이 반영됩니다.

## 참고
- <새 레슨 · 질문> 탭의 AI 기능은 Claude 앱 안에서 열었을 때만 동작합니다.
- 영상 링크는 2026년 11월 기준으로 확인했습니다. 유튜브 영상이 내려가면 링크가 깨질 수 있습니다.
