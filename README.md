# 콘텐츠 코드북

뛰어난 광고, 뮤직비디오, 예고편, 해설 영상을 직접 보면서 그 안에 쓰인 연출 공식을 익히는 안목 훈련 앱입니다. SP미디어텍 내부용.

- **오늘**: 오늘의 한 편과 <먼저 볼 영상 코스>
- **영상관**: 🔥 인기 · 💡 인사이트 · 🎬 영상미로 골라 보기. 누르면 앱 안에서 재생
- **영상** 176편 · **공식 코드** 59개 (9개 분야) · **레전드 사례** 18개 · 차용 연습 · 연령대 지도 · 트렌드 · 퀴즈

## 휴대폰에 설치
- 아이폰: 사파리로 페이지 열기 → 공유 단추 → <홈 화면에 추가>
- 안드로이드: 크롬으로 열기 → 메뉴 → <앱 설치> 또는 <홈 화면에 추가>

## 무엇이 어디 있나

| 파일 | 무엇인가 |
|---|---|
| `index.html` | 화면 틀 (탭과 빈 칸들) |
| `css/app.css` | 디자인 (색·글꼴·배치) |
| `js/app.js` | 화면 동작 (재생, 고르기, 퀴즈, 기록 저장) |
| `js/viz.js` | 공식 코드 카드의 원리 도식 그림 |
| `data/videos.json` | **영상 목록.** 영상을 더하거나 뺄 때 고치는 곳 |
| `data/course.json` | <먼저 볼 영상 코스>의 순서 |
| `data/codes.json` | 공식 코드 59개 |
| `data/cases.json` | 레전드 사례 18개 |
| `data/quiz.json` · `maps.json` · `trends.json` | 퀴즈 · 차용/연령대 지도 · 트렌드 |
| `tools/check-links.js` | 영상 연결 점검 도구 |
| `sw.js` · `manifest.webmanifest` · `icons/` | 홈 화면 설치와 오프라인용 |

앱을 고친 뒤 번호를 올릴 필요는 없습니다. 인터넷이 되면 항상 새 파일을 먼저 받습니다.

## 영상을 넣는 규칙

1. **특정 영상 하나의 주소만** 넣습니다. 검색 주소, 채널 주소, 재생목록은 넣지 않습니다.
2. 넣기 전에 반드시 확인합니다: `node tools/check-links.js --id 영상ID` → `정상` 이 나와야 합니다.
3. 되도록 **공식 채널**이 올린 것을 씁니다. 개인이 다시 올린 것은 언제든 내려갈 수 있습니다.
4. 확인하지 못한 수상 내역·기록은 적지 않습니다 (`fact` 칸을 비워 둡니다).
5. 영상은 유튜브·비메오 원본에 연결만 합니다. 내려받거나 다시 올리지 않습니다.

`data/videos.json` 의 영상 한 편은 이렇게 생겼습니다.

```json
{
 "id": "유튜브 영상 ID",
 "title": "화면에 보이는 이름",
 "maker": "브랜드·감독", "year": 2019, "kind": "광고",
 "tags": ["pop", "insight", "beauty"],
 "fact": "왜 뛰어난 작품인지 근거 한 줄", "fact_src": "근거를 확인한 주소",
 "point": "무엇을 볼까",
 "look": ["볼 때 확인할 것 1", "확인할 것 2"],
 "codes": ["H1", "E3"],
 "notes": {"H1": "이 영상에서 그 공식이 어떻게 쓰였나"}
}
```

`tags` 는 pop(인기) · insight(인사이트) · beauty(영상미) 가운데 해당하는 것만 적습니다.

## 영상 연결 점검

저장소 폴더에서 아래를 돌리면 모든 영상이 살아 있는지, 앱 안에서 재생되는지 확인합니다.

```bash
node tools/check-links.js
```

`영상 N편 가운데 문제 0편` 이 나오면 정상입니다. 문제가 있으면 어떤 영상인지 목록으로 나옵니다.

## 기록은 어디에 남나

본 영상, 내 레퍼런스, 장면 메모, 익힌 코드, 퀴즈 점수는 **그 기기의 브라우저 안**에만 저장됩니다. 휴대폰과 컴퓨터의 기록은 아직 서로 이어지지 않습니다.

## 참고
- <질문하기> 탭은 AI를 직접 부르지 않습니다. 질문문을 복사해 주면 Claude 앱에 붙여 넣는 방식이라 비용이 들지 않습니다.
- 유튜브 영상이 내려가면 연결이 깨집니다. 위 점검 도구로 주기적으로 확인하세요.
